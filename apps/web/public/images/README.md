# Website Asset Sources

The product screenshots show Hisaab with illustrative records, not customer data.

| Asset | Source |
| --- | --- |
| `hisaab-overview.webp` | Hisaab desktop overview capture. |
| `hisaab-sale.webp` | Hisaab sale-entry capture. |
| `hero-desktop.webp` | Composition from the desktop overview capture. |
| `hero-mobile.webp` | Composition from a mobile capture using illustrative books. |

These WebP files are prepared website assets. Keep the illustrative-record labels
when reusing them.

Nunito fonts are served locally from `apps/web/app/fonts` using `next/font/local`.
The bundled [OFL.txt](../../app/fonts/OFL.txt) contains the copyright notice and
SIL Open Font License 1.1; retain it with the font files.
